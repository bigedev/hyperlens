# hyperlens

源镜（hyperlens）：Markdown 与 HTML 的**源码关联预览**。

渲染出来的页面、大纲与语法树共用**同一套坐标** —— Markdown 用源码行、HTML 用
DOM 路径 —— 编辑器因此能在正文与预览之间来回移动时不必猜。

[English](README.md) | 简体中文

> **状态：0.1.0 开发中，尚未发布。**

## 它做什么

- **渲染**：把 Markdown / HTML 文档变成宿主自己 WebView 里显示的那份载荷 ——
  不带自己的 widget，也不对宿主的版式发表意见。
- **双向映射**：报告读者滚到了哪一行（HTML 侧是哪个 DOM 路径），下次打开再把
  预览送回原处。
- **大纲与语法树**：与预览同一次解析得出，抽屉、缩略图与正文不会互相打架。
- **命中定位**：搜索结果滚进视野并保持高亮，回执会说明锚点有没有找到。

## 它不做什么

- 不带页面 widget、路由与主题系统 —— 外壳归宿主。
- 不做编码检测：字节怎么解是调用方的事。
- 不联网：资产随包发布。

## 安装

```yaml
dependencies:
  hyperlens: ^0.1.0
```

宿主的 WebView 需要能通过 `packages/hyperlens/...` 加载包内资产；路径以常量形式
公开，宿主里不硬编码。
